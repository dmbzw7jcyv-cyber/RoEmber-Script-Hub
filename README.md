Community Roblox script repository for use with [RoEmber](https://github.com/yourusername/roember). Open source scripts for research, learning, and private server use.

## What This Is

Ember Scripts is a public collection of Lua scripts that work with the RoEmber executor. Scripts are organized by category and are free to use, modify, and distribute under GPL v3.0.

## Categories

| Category | Description |
|----------|-------------|
| `universal/` | Scripts that work in most games |
| `combat/` | Combat-related scripts and aim assists |
| `utility/` | Quality of life scripts and tools |
| `game-specific/` | Scripts for specific Roblox games |

## Script List

### Universal
- `infinite-jump.lua` — Makes your character jump infinitely high
- `esp.lua` — Highlights all other players with a red outline
- `fly.lua` — Allows free flight
- `speed-hack.lua` — Increases movement speed
- `noclip.lua` — Walk through walls
- `anti-afk.lua` — Prevents idle kick

### Combat
- `aim-assist.lua` — Basic aim assist for shooting games
- `kill-aura.lua` — Damages nearby enemies
- `hitbox-expander.lua` — Expands hitbox size

### Utility
- `auto-clicker.lua` — Clicks automatically
- `teleport.lua` — Teleports to saved position
- `infinite-yield.lua` — Loads Infinite Yield

## Usage

1. Download [RoEmber](https://github.com/yourusername/roember)
2. Attach RoEmber to Roblox
3. Copy a script from this repository
4. Paste it into the RoEmber editor
5. Execute

Or download scripts directly:

```bash
git clone https://github.com/yourusername/ember-scripts.git
```

Script Format

Scripts should follow this format:

```lua
-- Script Name
-- Description: What the script does
-- Author: Your name
-- Version: 1.0
-- Game: Universal (or specific game name)

-- Your script code here
```
